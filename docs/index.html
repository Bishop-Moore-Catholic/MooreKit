Usage documentation

Get started with MooreKit

MooreKit is a scoped component and utility framework for Bishop Moore Catholic pages. Include the CSS, wrap your page content with .bmc-v3, and compose responsive components without leaking styles into the rest of the site.

Namespace rule: every framework selector is scoped under .bmc-v3. Add that wrapper once around the content you want MooreKit to style.

Quick start

Use the stylesheet on every MooreKit page. Add the JavaScript bundle only when the page includes a carousel.

Starter template

<!doctype html> <html lang="en"> <head> <meta charset="utf-8"> <meta name="viewport" content="width=device-width, initial-scale=1"> <title>MooreKit page</title> <link rel="stylesheet" href="bmc-v3.css"> </head> <body> <main class="bmc-v3"> <section class="bmc-section"> <div class="bmc-container"> <span class="bmc-eyebrow">Bishop Moore Catholic</span> <h1 class="bmc-heading-1 bmc-heading-split">Build <strong>Something Moore</strong></h1> <p class="bmc-lead">Compose scoped components and utilities.</p> </div> </section> </main> <script src="bmc-v3.js" defer></script> </body> </html>
